## 📊 Retail Sales Forecasting & Inventory Optimization

📝 Project Overview
---

This project focuses on building a machine learning–based retail sales forecasting system using historical sales data.
Accurate demand forecasting helps retailers reduce stockouts and overstock situations, improve inventory planning, and support data-driven decision-making.

The project was developed as part of a Data Science Internship and follows an end-to-end data science workflow.

---

🎯 Objectives
---

Forecast future retail sales using historical data

Improve forecasting accuracy using machine learning models

Reduce stockout rate by at least 15%

Reduce overstock rate by at least 10%

Analyze business impact using evaluation metrics

---

📂 Dataset
---

Size: 6,432 rows × 13 features

Type: Time-series retail sales data

Features include:

Weekly sales

Holiday flag

Fuel price

CPI

Unemployment

Date-based features

Lag features and rolling mean

---

🔧 Data Preprocessing
---

Handled missing values

Converted date columns

Feature engineering (lag features, rolling mean)

Removed invalid and null entries

---

🛠️ Technologies Used
---

Python

Pandas & NumPy – Data manipulation

Matplotlib & Seaborn – Data visualization

Scikit-learn – Machine learning models

Random Forest Regressor

---

🔍 Methodology
---

Data loading and cleaning

Exploratory Data Analysis (EDA)

Feature engineering

Train-test split using time-based logic

Model training and tuning

Model evaluation

Inventory optimization analysis

---

📈 Model & Evaluation Metrics
---

The Random Forest Regressor was used for forecasting.

Evaluation Metrics:

Mean Absolute Error (MAE)

Root Mean Squared Error (RMSE)

Mean Absolute Percentage Error (MAPE)

Forecast Accuracy

---

✅ Results
---

Forecast Accuracy: 88.87%

Stockout Rate: 15.3%

Overstock Rate: 17.09%

📌 The results meet the project objectives and demonstrate effective demand forecasting and inventory optimization.

---

🏁 Conclusion
---

This project demonstrates how machine learning techniques can be applied to real-world retail data to improve sales forecasting accuracy and inventory management.
It highlights the importance of data preprocessing, feature engineering, and model evaluation in achieving reliable results.
